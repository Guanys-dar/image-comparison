# 图片对比评估

请用电脑上的 Chrome 或 Edge 浏览器打开：https://guanys-dar.github.io/image-comparison/

使用组织者分配的组别和匿名编号。每组共 21 对图片，每对只回答一个总体偏好问题，包括阅读说明在内最多花 15 分钟。达到 15 分钟时请停止并导出已有答案，未完成也可以导出。

开始前请阅读[操作指南](HOW_TO.md)和[评分说明](RATER_INSTRUCTIONS.md)。所有图片提示词均显示中文译文。点击“导出答案”，将下载的 JSON 文件私下发给组织者；网页不会自动提交，请勿将答案上传到公开仓库。

本仓库仅包含志愿者使用的网页、显示图片和说明。访问网页不需要 GitHub 账号。
